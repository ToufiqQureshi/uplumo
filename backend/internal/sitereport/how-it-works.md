# How it works

1. Open **Reports** and click **Create client report**.
2. Pick the period (7 days, 28 days or 3 months). The window ends three days
   before today, because Google Search Console's numbers are final then. Each
   number is compared with the same number of days just before.
3. Pick the sections. All are on by default.
4. Optionally write a message to the client and next steps.
5. Leave **Create a client link** on to get a public link straight away.
6. Click **Create report**. The report opens; if a link was made it is copied.
   Sections without data (say, Analytics not connected) are left out and the
   toast says why, so you know what to connect.

The client sees one page: headline numbers, highlights, then each section.
Everything is clickable without sign-in: the section bar jumps, tabs switch
between top searches, pages, rising and falling searches and countries,
keyword filters show top 10, movers or lost keywords, audit issues expand to
show the affected pages, and chart points show the day's value on hover.
The report is a snapshot: re-create it to refresh the numbers.
