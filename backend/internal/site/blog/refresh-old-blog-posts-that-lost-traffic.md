**Short answer:** Before rewriting an old blog post, compare its clicks, impressions and queries in Search Console, check whether the search intent changed, and inspect the page for outdated or incomplete advice. Update only what improves the answer; combine or redirect pages only when they truly overlap.

![A refresh decision path: diagnose the drop, improve the answer, then measure again](/site/blog/content-refresh-decision.svg)

## First identify what changed

Compare the same dates across years when seasonality matters. In Search Console, review the page and its queries. Ask:

- Did clicks fall while impressions stayed similar? The result may be less compelling or competition may have changed.
- Did impressions fall too? Demand, indexing, ranking or page relevance may have changed.
- Did only one query group decline? The page may have lost a specific section or no longer match that intent.
- Did a site migration or template change happen? Check canonical, redirects, internal links and indexing.

A single week is rarely enough to prove a lasting trend. Search demand and result layouts change.

## Check the page against today’s question

Search the main query and inspect the current results. Does the page answer the same question people now ask? Are details out of date? Are prices, product features, screenshots or official instructions still accurate? Add a clear updated date only when the page has had a meaningful review.

Do not change the publication date just to make an old page appear new. Google advises making substantial changes visible when appropriate and keeping content accurate for readers.

## Choose the right action

- **Update:** The page still serves the same purpose but needs current facts, better examples or clearer steps.
- **Expand:** A real sub-question is missing and belongs on this page.
- **Split:** The page is trying to answer two different intents, and each deserves a useful destination.
- **Combine:** Two pages substantially repeat the same answer and one stronger page would serve the reader better.
- **Redirect:** A page has moved or been retired and a genuinely relevant replacement exists.
- **Leave it:** The page is still accurate, useful and meeting its goal even if search clicks are lower.

Do not delete a page only because it has low traffic. It may help existing customers, support a sales journey or serve a narrow but valuable question.

## Improve the article with evidence

Add first-hand examples, verified information, screenshots you own, a clearer process, and links to current official sources. Replace generic opening paragraphs with a direct answer. Check headings and links. Remove claims that cannot be supported.

After publishing the update, record the changes and measure the same queries and business outcomes again. Search engines may need time to recrawl, and a change does not guarantee a recovery.

If you are diagnosing broader losses, use [Google Search Console](/blog/google-search-console-for-small-businesses), [an SEO audit checklist](/blog/seo-audit-that-finds-real-problems) and [an article brief](/blog/seo-content-brief-for-small-business).

## Use a small refresh log

Keep the old URL whenever the page still serves the same need. Record the date, queries reviewed, sections changed, source links checked and reason for the update. If you combine two articles, make one page the clear destination and redirect the retired URL to the closest useful replacement.

After the update, check whether the page is accessible and request a recrawl if needed. Then compare the same query group, not just total site visits. Also check enquiries: an article may bring fewer visitors but still assist an important purchase.

If the page is about a stable topic and remains accurate, a lower click count may reflect changing demand or result layout rather than a content fault. Use evidence before investing in a rewrite.

## Turn a vague refresh into a specific editorial change

Use a change sheet before editing:

| Field | Example for a hypothetical analytics guide |
| --- | --- |
| Main question | How to identify visits from AI assistants |
| Decline | Relevant query clicks fell over comparable periods |
| Verified factual gap | Official channel definitions changed |
| New value | Current instructions, attribution limits and a reproducible check |
| Preserved material | Useful source/medium explanation and stable URL |
| Review evidence | Current official documentation and accurate examples |

A meaningful update corrects the old instructions and removes contradictions throughout the article. Appending a current paragraph while leaving the old false short answer in place still misleads readers. Check the title, description, image labels, FAQ and internal links as well as the main body.

When comparing results, preserve the old query set and look for new relevant queries separately. Otherwise, added impressions for broad low-intent searches can disguise a continued loss on the important task. Also record whether Google has recrawled the updated page before judging its search effect.

For an overlapping article, compare every unique example and incoming link before merging. If the second article serves a distinct troubleshooting need, strengthen the link between them rather than collapsing it into a sprawling general guide.

Set the updated date only after a substantive review like this. A date change, synonym replacement or arbitrary word-count increase is not a refresh strategy. For stable low-demand topics, retaining an accurate concise answer may be the right editorial decision even when it never becomes a high-traffic article.

## FAQ

**How often should I update a post?**

Review content when facts can become stale, when important queries change or when Search Console shows a meaningful shift. Do not update only to change the date.

**Should I delete pages that get no clicks?**

Check links, usefulness, conversions and purpose first. A page can have value outside organic traffic.

**Can updating guarantee recovered traffic?**

No. A strong update improves accuracy and usefulness, but search results can change for many reasons.
