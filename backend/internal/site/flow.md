# Public page flow

Browser GET → HTTP router → Site's pre-rendered page → HTML with shared theme and assets. `/careers` is registered through `InfoPaths()` without authentication and enters the sitemap automatically.

Apply → visitor's email application with `SupportEmail` and the selected role in its subject. The visitor writes and sends the application. No application is submitted or stored by Uplumo. Paid provider calls: 0 on load, expand or Apply. Customer credits: 0.
