01 / Backend engineering

Go Developer

Build the backend behind Uplumo's SEO and AI search tools, with reliable APIs and predictable costs.

Responsibilities & skills

What you'll build

  • Go APIs, background jobs and third-party integrations.
  • PostgreSQL queries, Redis caching and request deduplication.
  • Reliable error handling, tests and safeguards against duplicate API charges.

What you'll bring

  • Practical experience with Go, HTTP APIs and SQL.
  • An understanding of concurrency, timeouts and secure backend development.
  • The ability to debug existing code and explain your decisions clearly.

02 / AI engineering

AI Agent Developer

Build agents that use tools and website data to help people investigate search problems and take useful action.

Responsibilities & skills

What you'll build

  • Tool-calling workflows with structured outputs and clear user controls.
  • Connections between AI models, product APIs and relevant website context.
  • Evaluations for answer quality, failure handling, latency and cost.

What you'll bring

  • Experience integrating LLM APIs and building agent workflows.
  • Strong programming skills and an understanding of retrieval and tool calling.
  • A practical approach to prompt injection, permissions and testing AI output.

03 / Search engineering

Programmatic SEO Developer

Build systems for useful, data-driven pages that people can discover, navigate and learn from.

Responsibilities & skills

What you'll build

  • Page templates and publishing workflows backed by relevant data.
  • Internal linking, metadata, sitemaps and structured data where appropriate.

  • Examples of SEO automation or template-based pages you've built or improved.
