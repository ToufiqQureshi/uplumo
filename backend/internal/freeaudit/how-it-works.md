# How the free audit works

1. Paste a page address (for example `yourwebsite.com`) and press Run.
2. We read that one page the way a search engine or AI crawler does: the HTML the server sends, your robots.txt, llms.txt and sitemap.
3. We run about 40 checks in four groups: on-page SEO, AI search (AEO), technical and content. Each check says what we found, why it matters and how to fix it.
4. The score is a weighted average of the four groups. Serious problems cap it: a critical failure (for example AI crawlers blocked, or no HTTPS) holds the score at 59 or lower; a high-impact failure holds it at 79 or lower. Five or more warnings hold it at 89. The report lists the reasons under "Why the score is limited".
5. Download the report as a PDF (your browser's print window; choose "Save as PDF") or as a Word file. The Word file is only available for a page you have already checked in the last day.

The score measures how ready the page is for Google and AI search. It does not
measure rankings, backlinks or whether AI assistants mention you.

Results are kept for 24 hours, so running the same page again shows the same
result. If a page is unreachable we say why and do not score it.
